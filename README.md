# 棋譜ならべ音ゲー 〜耳赤の一局〜

囲碁の名局を、音楽に合わせて一手ずつ並べていくリズムゲームです。
曲が終わるころには、本因坊秀策の「耳赤の一局」を一局並べ終えています。

**▶ ブラウザで遊ぶ：** https://nao838861.github.io/kifu-rhythm/

インストール不要です。PC・スマホのブラウザで、音を出して遊んでください。

## 遊び方

- 盤上に、次の一手の位置へ縮んでいくリングが出ます（黒番は黒、白番は白のリング）。
- リングが石と重なる瞬間に、その交点をタップ（クリック）します。
- 判定は PERFECT / GREAT / GOOD / MISS。ミスしても石は自動で置かれ、対局は最後まで進みます。
- 石が取られると爆発します。127手目「耳赤の一手」で最高潮に。

## 設定

| 項目 | 内容 |
|---|---|
| コース | 耳赤まで（127手）／全局（325手） |
| モード | ふつう（位置をタップ）／かんたん（どこをタップしてもOK・キー入力も可） |
| テンポ | ゆっくり／ふつう／はやい／とてもはやい（曲は「はやい」のまま、2倍のペースで打つ） |

「耳赤まで」を打ち終えたら、結果画面の「続けて最後まで打つ」で、そのまま325手の終局まで続けられます。

曲『山の魔王の宮殿にて』は、だんだん速く、だんだん豪華になっていきます。

## クレジット

- 棋譜：黒 安田秀策（本因坊秀策）四段 vs 白 井上幻庵因碩 八段（1846年・黒2目勝ち）
  棋譜データは [Andries Brouwer 氏の秀策棋譜集](https://homepages.cwi.nl/~aeb/go/games/games/Shusaku/)（game 126）を使用
- 曲：グリーグ『山の魔王の宮殿にて』（『ペール・ギュント』第1組曲より）
  [Mutopia Project のパブリックドメイン楽譜](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=1888)をもとに、ブラウザ内で音を合成しています（録音は使っていません）
- 原案：「棋譜並べ音ゲー」のアイデア（囲碁シル開発者 natsuki_kibe さんのポストより）

## 技術メモ

`index.html` 1ファイルだけで動きます（外部ライブラリ・サーバー不要）。音はすべて Web Audio API で合成しています。
